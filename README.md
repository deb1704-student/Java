# Java Mastery

A structured Java learning and problem-solving repository — from fundamentals to advanced Java and LeetCode/DSA.

## Goals

- Build strong Java fundamentals from scratch
- Master `String`, arrays, collections, OOP, exceptions, generics, and Java I/O
- Solve Data Structures & Algorithms problems in Java
- Organize LeetCode solutions by problem pattern
- Maintain clean, compilable, interview-ready code

## LeetCode Solution Format

Every problem will follow this format:

1. **Problem statement**
2. **Examples**
3. **Constraints**
4. **Brute-force idea** when useful
5. **Optimized approach**
6. **Java solution**
7. **Time complexity**
8. **Space complexity**
9. **Edge cases**
10. **Key takeaway / pattern**

## Java Version

Target: **Java 21 LTS**.

## Progress

This repository is being built progressively. The objective is not to dump solutions, but to create a searchable Java mastery system where each topic is learned, implemented, and reinforced through problems.

## Principles

- Prefer readable Java over clever Java.
- Understand the pattern before memorizing the solution.
- Record complexity for every DSA solution.
- Keep LeetCode-compatible solutions separate from standalone practice programs.
- Add tests/examples whenever practical.
